# 🕷️ SM Click — Dark Docs (Halloween Edition 2026)

> **“A documentação que o seu número gostaria que você nunca encontrasse.”**  
> 🎃 *Os Monstros do Suporte — O Terror dos Atendimentos*

Aplicação web responsiva (mobile-first) criada como **paródia interna de Halloween** para a equipe de suporte da **SM Click**, protagonizada pelo personagem **#6 — A Aranha dos Links**.

---

## ⚠️ Aviso Importante

**Este site é uma paródia interna criada para uma ação de Halloween e não representa documentação oficial ou orientação real da SM Click ou do WhatsApp.**
- Não coleta dados pessoais, credenciais, tokens ou números reais.
- Não realiza requisições externas para URLs digitadas no verificador.
- Todos os números exibidos no Cemitério de Números são fictícios e mascarados (`+55 XX 9****-XXXX`).

---

## 🚀 Como Executar

```bash
# Instalar dependências
npm install

# Rodar servidor de desenvolvimento
npm run dev

# Gerar build de produção
npm run build
```
